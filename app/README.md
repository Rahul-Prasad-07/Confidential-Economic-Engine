# MagicBlock Agentic Privacy Desk Frontend

Fresh frontend rebuilt from scratch with a premium Cosmos-inspired editorial style.

## Run locally

```bash
yarn install
yarn dev
```

## Production build

```bash
yarn build
yarn start
```

## Notes

- Network selector supports `devnet` and `localnet` UI context.
- Wallet connection uses Phantom/Solflare adapters.
- Console actions are currently UX-first simulation hooks ready for on-chain/API wiring.
